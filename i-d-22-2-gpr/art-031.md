# Art. 31 Mehrfach Vorgeschlagene
1 Steht ein Vorgeschlagener auf mehr als einem Wahlvorschlag desselben Wahlkreises, so fordert ihn die Wahlbehörde auf, binnen drei Tagen zu erklären, auf welchem Vorschlag sein Name stehen soll. Erfolgt keine Erklärung, so wird der Name auf allen Vorschlägen gestrichen.
