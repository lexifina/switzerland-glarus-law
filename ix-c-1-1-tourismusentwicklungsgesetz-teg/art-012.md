# Art. 12 Grundsatz
1 Die Gemeinden erheben eine Kurtaxe für das Beherbergen von Gästen. Sie können ausserdem eine Tourismusförderungsabgabe erheben.
2 Als Beherbergen gilt das entgeltliche und unentgeltliche Überlassen von Wohnraum, Platz in einem Massenlager oder der Möglichkeit zum Campieren. Dauert das Überlassen länger als einen Monat, so können Pauschalen geleistet werden.
3 Die Gemeinden haben die Bestimmungen über Kurtaxen und Tourismusförderungsabgaben dem zuständigen Departement zur Genehmigung vorzulegen.
